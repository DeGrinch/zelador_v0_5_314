## ⚙️ TECHNICAL OVERVIEW
1. Total map scale: 41 km × 41 km (≈ 1,677 km² worldspace)  
2. Landmass (playable area): ≈ 75 km²  
3. Ocean area: ≈ 1,600 km² of navigable space  
4. Playable surface roughly equivalent to Namalsk  
5. The ocean is fully accessible but contains no static builds  

**MapGroupPos.xml:**  
6. ~12,000 entries defining placed objects and loot spawn points  

**MapGroupProto.xml:**  
7. Each entry links to a prototype defining 3–10+ spawn locations  
8. Total CE spawn points range from 36,000 to 120,000+  

**MPMission:**  
9. Custom economy and mpmission configs under development  
10. Recommended: use these configs for balanced testing  
11. Contributions and feedback from server owners are encouraged
